# Task 4C Round 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the Task 4C rereview gates with real child execution, convergent cancellation, reference-preserving migration behavior, one canonical deliverable stream, and mutation-sensitive retry tests.

**Architecture:** Preserve existing durable identities and centralize deliverable stream predicates in a small query-policy module. Extend the revision owner and SkillRuntime at their existing seams: cancellation is transaction-neutral until the existing runtime close commits, while composite execution dispatches actual child capabilities and records actual child SkillRuns before the parent can complete.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy async ORM, Alembic, PostgreSQL/SQLite, pytest, Ruff, mypy.
