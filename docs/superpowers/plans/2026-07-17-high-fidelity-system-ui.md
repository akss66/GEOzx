# 全系统高保真 UI 落地计划

## 目标

将用户确认的运营大脑高保真稿扩展为全部桌面端页面的统一设计系统，不改变既有真实业务接口和数据模型。

## 实施顺序

1. 统一颜色、字体、圆角、间距、阴影和 Ant Design 主题令牌。
2. 对齐 App Shell、客户/项目切换、平台/账号上下文、搜索、通知和用户区。
3. 重构运营大脑空态、对话态、专家接力、成果与确认面板。
4. 收口账号矩阵、内容生产、人工审批和运营复盘。
5. 收口专家团、知识库、使用成本、用户管理、专家管理和模型基础设施。
6. 运行测试、构建、Lint，并在桌面浏览器逐页截图验收。

## 约束

- 本轮只做桌面端。
- 不部署线上，直至用户明确批准。
- 不引入 Mock 数据。
- 不改变 OAuth、Agent Runtime、审批和数据回流合同。
- 不使用页面级卡片墙、装饰渐变、发光元素或大面积灰色后台底色。
