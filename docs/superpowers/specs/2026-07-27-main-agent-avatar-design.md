# 主 Agent 独立头像设计

## 目标

将用户提供的黑色旋涡图形作为主 Agent 的身份头像，并与“同舟行”平台品牌 Logo 明确分离。

## 范围

- 新增独立的主 Agent 头像资源 `frontend/public/main-agent-avatar.png`。
- 头像保持黑色，背景为真实透明通道，不保留源 JPG 中的棋盘格。
- 所有通过 `AgentAvatar` 渲染的 `00-decision` 主 Agent 身份统一使用新头像。
- 运营大脑欢迎区中直接渲染的主 Agent 头像改用新资源。
- 覆盖会话标题、运营决策记录、思考中状态和主 Agent 消息等现有 `AgentAvatar` 消费位置。

## 明确不改

- `frontend/public/logo.png` 保持原样。
- 左上角平台品牌、登录页品牌和其他“同舟行”Logo 不替换。
- 专家 Agent 的图标、颜色和头像规则不变。
- 不修改后端 Agent 数据模型或 API。

## 实现方案

采用独立 PNG 资源，而不是 CSS 遮罩或内联 SVG：

1. 从源图提取黑色图形，移除已经烘焙进 JPG 的棋盘格。
2. 输出带 Alpha 通道的方形 PNG；四周保留少量安全留白，避免小尺寸裁切。
3. 在前端集中定义主 Agent 头像资源路径，避免欢迎区和头像组件再次引用平台 Logo。
4. 沿用现有头像容器的尺寸、圆角、边框和无障碍语义，仅按黑色图形调整 `object-fit` 和内边距。

该方案资源语义清晰、浏览器兼容性稳定，也能避免平台品牌与 Agent 身份再次耦合。

## 验收标准

- 主 Agent 欢迎区、消息头像、会话身份和运营决策记录显示黑色新头像。
- 左上角“同舟行”平台 Logo 与登录页 Logo 仍显示原品牌资源。
- 新 PNG 经像素格式检查确认包含 Alpha 通道。
- 头像在浅色和深色主题下都清晰可辨。
- 现有主 Agent 头像测试更新为新资源路径，并先验证旧实现下测试失败。
- 前端相关测试与生产构建通过。
