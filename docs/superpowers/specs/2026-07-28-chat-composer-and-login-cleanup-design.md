# Chat 输入器与登录表单清理设计

## 目标

修正两处影响产品质感和安全感的界面问题：

1. 将运营大脑欢迎区的输入器调整为接近 ChatGPT 的浮动对话输入形态。
2. 删除登录页硬编码的演示邮箱和密码，表单首次打开时保持为空。

## 输入器设计

- 保留现有 `BrainComposer` 组件、提交事件、Enter 发送、Shift+Enter 换行、停止生成和权限确认逻辑。
- 普通消息模式默认呈现为紧凑的单行浮动输入器，内容增加时自动增高，最多显示约六行，超过后内部滚动。
- 外层默认高度为 64px，使用 32px 大圆角、柔和浅色描边和轻阴影，避免扁平细条或大面积厚重阴影。
- 发送按钮为 36px 真圆形，固定在输入器右下角并保留约 12px 内边距；无输入或不可发送时弱化，有有效输入时使用现有品牌红色。
- 欢迎区和已有消息流共用同一套输入交互；欢迎区只控制最大宽度和垂直位置，不再强制三行高度。
- 已移除的快捷提示按钮不恢复。

## 登录表单设计

- 删除 Ant Design `Form` 上的 `initialValues` 演示凭据。
- 邮箱和密码字段首次渲染均为空，保留浏览器标准的 `email` 和 `current-password` 自动填充能力。
- 不增加示例邮箱或密码占位符，不改变校验规则、登录接口、错误提示和成功跳转。

## 验收标准

- 空白欢迎页中的输入器默认紧凑，不再呈现大块空白矩形。
- 输入多行内容时高度平滑增长，达到上限后在输入框内部滚动。
- Enter、Shift+Enter、发送按钮及生成停止功能保持原行为。
- 登录页源码和初始 DOM 中不再出现 `admin@qq.com` 或 `admin123`。
- 邮箱和密码在没有浏览器密码管理器介入时均为空。
- 前端测试、类型检查和生产构建通过；上线后浏览器实测布局、登录空态和控制台无新增错误。

## 非目标

- 不重做登录页整体视觉。
- 不修改认证协议、账号数据或线上管理员凭据。
- 不复制 ChatGPT 的品牌资产、颜色或专有图标，只采用其紧凑自适应的输入交互规格。
