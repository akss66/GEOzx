# 主 Agent 头像无框化设计

## 目标

移除主 Agent 头像外层的浅红描边、浅色底板和容器圆角，让黑色标记直接呈现在界面上，消除小卡片式的廉价感。

## 设计决策

- 全局修改主 Agent 头像基础样式，所有使用 `AgentAvatar` 的主 Agent 身份保持一致。
- `.tz-agent-avatar.is-main-agent` 不再绘制边框或背景，容器保持透明。
- 主 Agent 图片使用头像槽位的完整宽高；资源自身留白负责视觉安全区。
- 欢迎态、页面标题、消息流、运营决策记录和专家编排继续保留各自既有尺寸与对齐方式。
- 专家 Agent 的描边、底色和职能色不变。
- 平台 Logo 及其品牌展示不变。

## 验收标准

1. 主 Agent 头像在欢迎态、标题区和消息流中均无外框、无底板。
2. 黑色标记清晰完整，不被裁切或拉伸。
3. 头像与相邻文字的对齐和间距不发生回归。
4. 专家头像与平台 Logo 的视觉样式不受影响。
5. 前端测试和生产构建通过，浏览器控制台没有新增错误。

## 范围

本次只调整主 Agent 头像的全局视觉样式，不修改头像资源、组件结构、业务逻辑或其他身份系统。
