# 身份权限与模型基础设施治理设计

日期：2026-07-20
状态：已确认，待实施

## 1. 目标

本次重构同时解决两个治理缺口：

1. 将“成员与权限”从基础列表升级为可执行的身份、资源和安全治理工作台。
2. 将只支持服务器环境变量的模型配置升级为组织隔离、可扩展、可审计的多供应商基础设施。

系统继续服务代运营团队，并为后续多组织商用保留边界。任何权限或密钥规则都必须在后端强制执行，前端只负责表达和操作，不构成安全边界。

## 2. 已确认的产品决策

- 管理员拥有成员新增、查询、修改、禁用和永久删除能力。
- 禁用等同于软删除：成员不能登录，历史任务、审批、资产和审计保留。
- 永久删除会删除成员身份，以及该成员创建的任务、内容、交付物、审批、知识、发布包、成本和相关审计数据。
- 永久删除必须先展示影响预览，再验证成员邮箱和执行管理员自己的二级密码。
- 二级密码按管理员独立设置，不允许组织共享。
- 设置或重置二级密码前必须验证当前登录密码；设置或重置后有 10 分钟冷却期。
- 二级密码只保存不可逆哈希；连续错误触发短时锁定。
- 永久删除完成后仅保留一条脱敏删除凭证，记录执行管理员、时间、操作编号和删除数量，不保留被删除成员业务内容。
- 成员权限采用系统身份、客户角色、项目覆盖角色和账号范围共同计算。
- 模型供应商和 API Key 按组织隔离。
- 系统提供预置供应商，并允许管理员新增 OpenAI 兼容供应商；第一阶段不开放任意私有协议插件。
- 模型密钥由管理员在前端录入，但只交给后端加密保存和运行时使用，任何读取接口都不得返回完整密钥。

## 3. 成员治理模型

### 3.1 系统身份

保留现有系统身份：

- `admin`：组织管理员，拥有组织级治理权限。
- `user`：组织成员，只能访问被授权的业务资源。

系统必须始终保留至少一个启用中的管理员。管理员不得停用或永久删除自己，也不得移除自己的管理员身份。

### 3.2 资源权限

成员最终权限由四层共同决定：

1. 系统身份：管理员拥有组织级全局访问权。
2. 客户角色：负责人、运营、内容、审核，作为客户范围内的默认职责。
3. 项目角色：可覆盖客户默认角色。
4. 账号范围：`all_accessible` 继承可访问客户和项目下的全部账号，或 `selected` 仅允许访问明确选择的账号。

旧成员迁移为 `all_accessible`，避免升级后突然失去既有访问权。管理员不需要单独保存客户、项目或账号授权。

所有业务 API 必须调用统一权限服务计算最终范围。前端隐藏、路由拦截和按钮禁用都不能替代后端授权。访问无权资源时统一按不存在处理，防止泄露资源存在性。

### 3.3 成员状态

- 启用：可以登录并在授权范围内工作。
- 禁用：不能登录；现有访问令牌失效；历史数据保留。
- 永久删除：身份和归属数据不可恢复地删除。

禁用操作可恢复，永久删除不可恢复。

## 4. 管理员二级密码

新增管理员安全凭证记录，至少包含：

- `user_id`
- `password_hash`
- `changed_at`
- `delete_available_at`
- `failed_attempts`
- `locked_until`

二级密码规则：

- 长度 8 至 128 字符。
- 使用与登录密码同等级的密码哈希算法保存，不可解密或回显。
- 设置和重置时必须提交当前登录密码。
- 设置或重置后 `delete_available_at = changed_at + 10 分钟`。
- 连续 5 次验证失败锁定 15 分钟；成功验证后清零失败计数。
- 二级密码不得写入日志、事件、错误详情或前端存储。

## 5. 永久删除协议

永久删除采用两阶段协议，避免陈旧预览或误操作。

### 5.1 影响预览

`POST /users/{user_id}/deletion-preview`

返回：

- 成员基本标识。
- 各类待删除记录数量。
- 是否允许删除及阻断原因。
- 短时有效、一次性使用的 `preview_token`。
- 预览生成时间和数据版本摘要。

### 5.2 执行删除

`DELETE /users/{user_id}/permanent`

请求必须包含：

- `preview_token`
- 成员完整邮箱
- 执行管理员二级密码

服务端必须重新计算影响范围。若数量或版本摘要发生变化，拒绝执行并要求重新预览。删除在单个数据库事务中完成，任一关联删除失败则全部回滚。

删除范围包括该成员创建或直接归属的任务、运行时记录、工具调用、审批、内容、交付物、知识、发布计划、成本和相关事件。组织共享资源中不存在创建者关系的记录不得被误删。

事务完成前写入脱敏删除凭证。凭证不得包含被删除成员姓名、邮箱、内容或历史详情，只保留执行管理员、操作编号、时间和分类计数。

## 6. 成员管理界面

成员页面保持桌面端双栏结构，但升级为治理工作台：

- 页面进入后自动选中第一位成员，避免空白主面板。
- 顶部显示成员总数、启用、管理员、未分配资源和安全锁定数量。
- 左侧名册支持姓名/邮箱搜索，以及状态、系统角色和授权异常筛选。
- 右侧使用 `概览 / 资源权限 / 安全与登录 / 操作记录` 四个页签。

### 6.1 概览

- 编辑姓名、邮箱和系统角色。
- 显示启停状态、客户数、项目数、账号数和最近活动。
- 保存身份资料与资源授权是两个独立动作，避免无意覆盖。

### 6.2 资源权限

- 按客户展开项目，再展开账号。
- 客户角色是默认值，项目角色可覆盖。
- 账号范围可选择继承全部或仅指定账号。
- 页面持续显示最终生效权限摘要和未保存状态。

### 6.3 安全与登录

- 重置成员登录密码。
- 启用或禁用成员。
- 管理员设置或重置自己的二级密码。
- 永久删除位于独立危险操作区。

### 6.4 操作记录

- 显示成员资料、角色、授权、状态和安全操作时间线。
- 不展示登录密码、二级密码、API Key 或其他敏感值。

### 6.5 新建成员

现有“邀请成员”更名为“新建成员”。创建流程一次完成身份、初始密码、系统角色和初始资源授权。第一阶段不实现邮件邀请链路。

## 7. 模型供应商治理

### 7.1 供应商注册表

新增组织级供应商实体，至少包含：

- 组织、供应商代码和显示名称。
- 类型：预置模板或自定义 OpenAI 兼容。
- Base URL、启停状态和排序。
- 加密 API Key、密钥尾号和指纹。
- 验证状态、验证时间和安全化错误。
- 可用模型目录及更新时间。
- 创建者、更新者和时间戳。

供应商代码在组织内唯一。自定义供应商仅支持 HTTPS Base URL；服务端必须阻止私网、环回、链路本地和云元数据地址，防止 SSRF。

### 7.2 预置供应商

第一阶段提供可扩展模板，包括 DeepSeek、OpenAI、通义千问、豆包、智谱和 Moonshot。模板只提供名称、默认 Base URL、协议和常见模型，不包含凭证。

预置模板与自定义供应商使用同一运行时接口，不允许在 Agent 编排中写死 DeepSeek。

### 7.3 密钥生命周期

- 管理员可以新增、替换和删除 API Key。
- API Key 通过 HTTPS 提交，由后端使用现有凭证加密能力加密保存。
- 加密主密钥只存在服务器环境或后续 KMS/Vault 中，不与密文存放在同一数据记录。
- API 响应只返回 `credential_configured`、尾号、指纹摘要和更新时间。
- 保存后前端立即清空输入值，不写入 LocalStorage、SessionStorage 或 URL。
- 日志、异常和审计事件必须经过密钥脱敏。

### 7.4 验证和模型目录

- `POST /model-providers/{id}/verify` 验证凭证和端点，返回延迟、状态和安全化错误。
- `POST /model-providers/{id}/discover-models` 读取兼容模型目录；不支持目录接口时允许管理员手工维护模型名称。
- 未验证成功的供应商不得成为新的 Agent 主路由。
- 删除正在被 Agent 路由引用的供应商必须被阻止，并返回受影响专家列表。

### 7.5 运行时

LLM Gateway 按组织、供应商和模型解析运行配置。DeepSeek 和其他 OpenAI 兼容供应商走统一适配器；供应商协议差异通过预置模板参数处理，不泄露到 Agent 代码。

现有 `env:DEEPSEEK_API_KEY` 配置继续兼容，并在迁移后表现为只读服务器凭证来源。管理员可选择替换为组织级加密凭证。

## 8. 模型基础设施界面

- 供应商列表显示未配置、待验证、可用、异常和停用状态。
- 支持从预置模板添加，也支持新增 OpenAI 兼容供应商。
- 编辑面板包含名称、Base URL、协议、API Key、模型目录和启停状态。
- 密钥保存后只显示尾号；替换密钥是明确动作。
- 验证连接显示延迟、模型数量和安全化错误。
- Agent 路由下拉按供应商分组；供应商异常时显示受影响专家，不静默改写路由。
- 删除前显示路由引用；存在引用时引导先迁移。

## 9. 安全与审计

- 所有成员治理和模型治理接口仅组织管理员可访问。
- 所有输入使用 Pydantic 严格校验，所有数据库操作使用 ORM 参数化查询。
- 自定义 Base URL 实施 HTTPS、DNS 解析、私网地址拒绝和禁止重定向。
- 密钥验证设置连接、读取和总超时，并限制响应大小。
- 审计新增、修改、启停、授权、二级密码变更、删除预览、永久删除、供应商验证、换钥和路由变更。
- 审计事件永远不记录密码、密钥、完整请求头或供应商原始错误正文。

## 10. 错误处理

- 资源越权统一返回 `404`，管理能力不足返回 `403`。
- 最后一个管理员、自删、冷却期、二级密码锁定、预览过期和预览失效使用稳定业务错误码。
- 供应商验证错误映射为认证失败、端点不可达、协议不兼容、超时和模型不可用，不向前端返回堆栈或完整上游响应。
- 所有不可逆操作失败时保持事务前状态。

## 11. 测试与验收

### 11.1 后端

- 管理员可新增、查询、修改、禁用和永久删除成员；普通成员全部返回 `403`。
- 不能停用或永久删除自己和最后一个启用管理员。
- 二级密码哈希保存，设置/重置要求当前登录密码，10 分钟冷却有效，错误次数触发锁定。
- 删除预览短时有效且一次性使用；影响范围变化时必须重新预览。
- 永久删除失败时事务回滚；成功后仅存在脱敏删除凭证。
- 客户、项目和账号三级权限真实限制读取与写入。
- 不同组织不能读取或使用彼此的用户授权、供应商、密钥、模型和调用账本。
- API Key 密文可正确解密运行，但任何 API、日志和事件不包含明文。
- 自定义供应商拒绝不安全 URL；预置和自定义供应商均可验证并路由调用。
- 被 Agent 路由引用的供应商不能删除。

### 11.2 前端

- 成员页自动选中第一位成员，四个页签完整显示并保留未保存状态。
- 新建、编辑、禁用、权限保存、密码重置和永久删除流程可键盘操作。
- 永久删除必须完成影响预览、邮箱确认和二级密码验证。
- 账号权限支持继承全部和仅指定账号。
- 供应商新增、编辑、验证、换钥、模型维护和删除状态清楚。
- 密钥保存后不残留在 DOM、缓存、错误文案或测试快照中。

### 11.3 发布门槛

- 后端相关 pytest 全部通过。
- 前端相关测试和完整构建通过。
- 执行依赖安全扫描和密钥泄漏扫描。
- 在桌面端完成本地真实交互验收。
- 用户确认本地版本后才能部署线上。

## 12. 非目标

- 第一阶段不实现邮件邀请和自助注册。
- 第一阶段不接入任意私有模型协议插件。
- 第一阶段不允许查看已保存 API Key 明文。
- 第一阶段不建设外部客户门户。
