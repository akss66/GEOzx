# 当前执行清单

> 更新时间：2026-07-06

## 当前产品方向

同舟行 AI 新媒体运营平台以 **AI + Agent + 运营** 为核心，不做传统运营后台。

用户应先选择当前平台和账号，再把运营目标交给运营大脑；主 Agent 负责拆解任务、调度专家 Agent、生成交付物、进入人工审批，并把执行和复盘链路沉淀下来。

## P1：运营大脑模块重构

- [ ] 运营大脑首屏围绕“当前抖音账号 + 主 Agent 输入 + 专家编排流”组织。
- [ ] 未选择账号时阻止创建任务，并引导用户切换或接入抖音账号。
- [ ] 创建任务时提交 `platforms:["douyin"]` 和当前 `account_ids`。
- [ ] 前端展示主 Agent 调用专家 Agent 的过程：开始、处理中、完成、交接、阻塞。
- [ ] 后端校验账号属于当前组织、平台匹配、授权状态满足当前动作。
- [ ] 工具调用统一写入 `AgentToolCall` 或现有等价账本，便于追踪、审批、计费和复盘。

## P2：发布准备与人工审批

- [ ] 内容生产页升级为发布包准备，不只做普通内容检查。
- [ ] 新增或完善发布包字段：平台、账号、内容类型、标题、正文、话题、素材、封面、定时、可见性、评论设置。
- [ ] 新增 `publish_package_prepare` 工具，负责校验发布包并写入工具调用记录。
- [ ] 人工审批页展示完整发布包、发布前检查结果和一键复制发布清单。
- [ ] 抖音正式发布权限通过前，审批通过后只标记为 `approved_for_manual_publish`，不自动发布。

## P3：账号矩阵与平台状态

- [ ] 账号矩阵清晰展示每个抖音账号的授权状态、数据同步状态、发布能力状态。
- [ ] 小红书、视频号保留占位能力和手动回填状态，不假装已接入。
- [ ] 修正“已配置/已授权”状态判断，不能只靠默认 secret 引用或手动标记冒充真实接入。
- [ ] OAuth token 需要真实安全存储或明确标记为未配置，避免 UI 显示已授权但后端不可用。

## P4：运营复盘与成本

- [ ] 运营复盘按当前账号读取任务、发布包、审批、工具调用和平台指标。
- [ ] 抖音数据回流优先使用官方 OpenAPI，审核通过前先保留可手动回填的统一数据模型。
- [ ] 使用成本纳入 Agent 调用、工具调用、模型 token 和素材生成成本。
- [ ] 复盘建议可以送回运营大脑，形成下一轮任务。

## 验收节奏

每完成一个模块，先本地验收，再部署：

1. 前端本地可打开并通过基本交互。
2. 后端接口有最小测试或可复现 curl/API 验证。
3. 当前模块的数据状态不虚假承诺能力。
4. 用户确认后再部署到公网服务器。
